# 🩸 DonorFinder++

DonorFinder++ is an emergency blood donor web application built to bridge the gap between blood seekers and donors with zero latency. 

### 🚀 Key Features
- **Instant Emergency Search:** Filter verified donors instantly by blood group and city/campus location.
- **Interactive GIS Mapping:** Real-time visual coordinate rendering powered by Leaflet.js and OpenStreetMap.
- **WhatsApp Deep-Linking:** Direct one-click WhatsApp communication (`wa.me`) to eliminate calling delays during critical medical emergencies.
- **Glassmorphic UI:** Modern, high-performance cyber-medical dark theme designed for mobile and desktop screens.
- **Secure Backend:** Built with Python Flask and SQLite with auto-migration database schemas.
